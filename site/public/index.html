Markdown for mobile

手機也能
好好用 Markdown(｡･ᴗ･｡)

Android 與 iOS 上的 Markdown 檢視器與編輯器。開本機檔案，或直接開 GitHub、Gist、HackMD 上的文件， 改完同步回原本的地方；要是別人已經先動過，itouMD 會攤開差異，讓你一塊一塊決定留哪一邊。

MIT 授權·Flutter·v1.3.4·無廣告、無帳號牆

通勤路上想到一句話，打開 HackMD 筆記直接補上去，不用等回到電腦前；改完就同步，團隊筆記也一樣。

被問到某個 repo 怎麼裝，輸入 owner/repo 就把 README 叫出來，連結、圖片、badge 都是渲染好的；登入後私有 repo 也讀得到。

手邊只有一份 .md，系統內建的檔案總管點開常常只有滿版原始符號，編碼不對還會變亂碼；itouMD 打開就是排好版的畫面，LaTeX 公式跟程式碼高亮也都在。

渲染

該顯示的都顯示，不打折

GitHub Flavored Markdown 是基本盤。HackMD 的容器語法、GitHub 的 alert 區塊、目錄展開， 這些平常會被其他 App 吃掉的語法，itouMD 都認得。

  • :::info、:::spoiler 容器語法，[TOC] 目錄展開，> [!NOTE] alert
  • LaTeX 數學公式：inline $…$ 與 display $$…$$ 都會正確排版
  • 程式碼區塊標了語言就自動高亮，附行號跟一鍵複製
  • 圖片點開全螢幕、雙指縮放，SVG badge 也不會破圖

編輯

在手機上打 Markdown，不再是折磨

螢幕下方常駐格式工具列，清單會自己接下一項，左側行號欄跟著內文捲動。 按下「完成編輯」後，預覽會自動捲回你剛才改的那一行——不用再從頭滑一次。

  • 粗體、斜體、標題、清單、引用、連結、程式碼區塊一鍵插入
  • 清單裡按 Enter 自動延續下一項，不用自己補符號
  • 選取一段文字就能叫出 AI 助理，只改那一段
  • 可以另存成 .md 到裝置上任何位置

HackMD

筆記直接列出來，不用先去複製網址

連結帳號之後，個人筆記與各個團隊的筆記會分組列在首頁，點開就看。 清單跟內容都會快取，離線時照樣讀得到，並清楚標示是離線版本。

  • 完整支援團隊工作區：瀏覽、讀取、同步回團隊
  • 點開筆記自動抓最新內容，不會改到舊版
  • 同步成功後 10 秒內可以復原，App 重開仍然有效
  • 本機留著最近 50 筆同步紀錄，什麼時候動過什麼一目瞭然

外觀

調到你看得舒服為止

淺色深色跟隨系統，而且兩種主題可以各自設定主色和背景色—— 面板色系自動衍生，文字對比跟著背景亮度調整，不會出現自訂完就看不清楚的窘況。

  • 8 種內建閱讀字體，還能匯入自己的 .ttf／.otf
  • 文字顏色有 9 種預設，也可以自己開調色盤挑
  • 閱讀字級跟介面字級分開控制，放大介面不會連內文一起變形
  • 所有偏好設定即時生效並自動保存

衝突合併

兩邊都改了，也不用有人被蓋掉

按下同步之前，itouMD 會先去雲端拿一份現在的內容，跟你載入時的版本、 以及你改過的版本做三方比對。對方新增或刪掉的段落自動併進來， 只有雙方都動到的同一塊才需要你出手。比對用的是自己寫的 Myers diff，有單元測試蓋著。

基準版本不會被偷換

就算你重開筆記、開啟時自動抓了最新內容，比對基準仍然是「這次載入時看到的內容」，所以雲端在那之後的變更一定抓得出來。

後悔了還來得及

同步成功的提示上有「復原」，10 秒內按下去就把雲端還原回去。設定裡也留著最近 50 筆同步紀錄。

行為可以自己定

遇到衝突要每次詢問、直接覆蓋還是取消，在設定裡選一次就好；「開啟時自動更新」也能關掉。

AI 助理，看過 diff 再套

潤飾、翻譯、縮寫、改寫、摘要、擴寫、整理成表格、建議標題……13 個快捷指令， 結果一律先顯示逐行差異（紅刪綠增），確定沒問題才套上去。 自由交流是多輪串流對話，每一輪都帶著整篇文件跟你選取的段落，所以它真的知道你寫了什麼。 預設走內建免費額度，也能換成自己的 OpenAI 相容端點與 API Key。

GitHub，登入不用自己產 Token

走 OAuth 裝置流程：App 給你一組代碼，在網頁貼上就完成授權（想用 PAT 也還留著）。 從 blob 頁面開的檔案，改完可以直接寫回 repo；以檔案 SHA 偵測衝突， 發現雲端動過就先進合併畫面，寫回之後同樣可以復原。

下載

取得 itouMD

都放在 GitHub Releases。Android 可以直接裝；iOS 目前只有需要自行簽章的預覽版——這點先講清楚。

ANDROID

正式簽章 APK

每個版本依 CPU 架構拆成多個 APK，檔案比通用版小很多。 2017 年後的手機幾乎都是 arm64-v8a，挑這個就對了。

arm64-v8aarmeabi-v7ax86_64

裝好之後 App 內的「檢查更新」會自己抓對應架構的檔案，之後就不用再挑了。

前往 Releases
iOS／iPadOS

未簽章預覽版

Prerelease 提供檔名含 unsigned.ipa 的產物，不能直接點擊安裝， 必須先用自己的 Apple ID 或 Team 重新簽章。

這不等同 App Store、TestFlight 或公開 Ad Hoc 發布；免費 Personal Team 的描述檔會定期到期，適合個人測試。 下載後可以用 shasum -a 256 -c SHA256SUMS 核對完整性。

開源

程式碼都在那裡

itouMD 是 MIT 授權的開源專案，用 Flutter 所寫。想知道它對你的資料做了什麼，或擔心有資安疑慮，看原始碼最快。

Token 放在系統金鑰庫

HackMD 與 GitHub 的憑證存進 Android Keystore／iOS Keychain，跟一般偏好設定分開保管，不會混在同一份檔案裡。

沒有自己的後端

你的筆記只在裝置、HackMD 與 GitHub 之間往返。唯一的中介是 AI 內建額度用的 proxy，換成自己的 API 端點就能整個繞開。

每次推送都跑 CI

dart format、flutter analyze、flutter test 三關都要過。差異合併那段演算法有單元測試守著。
